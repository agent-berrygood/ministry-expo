# 사진 넣는 곳

사진은 이 폴더에 **넣으면 생기고, 빼면 사라집니다.** 코드나 JSON은 고칠 필요가 없습니다.
개발 서버(`npm run dev`)가 켜져 있으면 저장하자마자 화면에 반영되고, 커밋·푸시하면 사이트에 반영됩니다.

## 인물 사진 (PRD 4.8)

모든 인물 사진은 **배경을 지운 투명 PNG**로 넣어 주세요. 배경이 남아 있으면 네모난 사진이 그대로 세워집니다.
배경 지우기는 이 저장소의 스크립트로 할 수 있습니다 (스튜디오 회색 배경 사진에 잘 맞습니다):

```
python -E -P scripts/cutout.py 원본.jpg photos/_clergy/plaza-1_홍길동 목사.png
```

| 누구 | 넣는 곳 | 사진 |
|---|---|---|
| 부스 담당자 (부장님) | `{부스ID}_{부서명}/staff.png` | **머리 위부터 허리까지**, 정면. 데스크 뒤에 서 있는 모습으로 나옵니다 |
| 입구 환영 (담임목사님) | `_entrance/` 안의 첫 번째 사진 | 머리 위부터 허벅지까지, 정장. 환영 데스크 뒤에 서 계신 모습으로 나옵니다 |
| 교역자 (목사님·전도사님) | `_clergy/{자리ID}_{이름 직분}.png` | 머리 위부터 허벅지까지, 정장. 데스크·조리대·광장 안내석 뒤에 서 계신 모습으로 나옵니다 |

- 교역자 자리 ID는 `public/data/layout.json`의 `figures.clergy`에 있습니다. 예: `young-adult-2_강세원 목사.png` → 청년2부 부스에 서고, 누르면 "강세원 목사님이에요 👋"
- 자리를 바꾸려면 파일 이름의 자리 ID만 바꾸면 됩니다 (예: `plaza-1_…` → `newcomer…` 자리를 layout.json에 추가).
- 파일 이름이 `_`로 시작하면 반영하지 않습니다 (지우지 않고 잠시 빼 둘 때).
- 부장님 사진이 없는 부스에는 실루엣이 대신 서 있고, 교역자 자리는 사진이 있을 때만 사람이 섭니다.
- 사진 속 위치 정보(GPS)는 자동으로 지워집니다.
- 같은 장소, 같은 조명에서 찍으면 결과가 가장 자연스럽습니다.

## 부스 활동 사진 (PRD 4.6, 준비 중)

`{부스ID}_{부서명}/` 폴더에 활동 사진을 넣으면 부스 정보 패널에 보이게 할 예정입니다.
